# Placement Preparation System

A Flask-based student placement preparation app for registering users, practicing coding skills, and taking a technical quiz.

## Features
- Student registration and login
- Secure password hashing
- Quiz scoring and result tracking
- Student dashboard with average performance summary
- Programming practice and landing pages

## Run locally

1. Open a terminal in this folder.
2. Install dependencies if needed:
   `pip install flask`
3. Start the app:
   `python app.py`
4. Open http://127.0.0.1:5000 in a browser.

## Notes
- The app uses SQLite for persistent student and quiz data.
- The default database file is `placement.db` in this folder.
